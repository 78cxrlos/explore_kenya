# Explore Kenya

## Project Overview

Explore Kenya is a multi-page travel website created as part of a Web Design assignment. The purpose of this project was to build a structured and well-organized website using HTML5 and basic CSS.

The website showcases popular tourist destinations in Kenya such as Nairobi, Mombasa, Masai Mara, and Diani, along with other attractions across the country.

---

## Website Structure

The website contains five pages:

- index.html (Home)
- destinations.html (Destinations)
- gallery.html (Gallery)
- about.html (About)
- contact.html (Contact)

Each page includes:

- A header
- A navigation menu
- A main content section
- A footer

All pages are linked using relative links to ensure proper navigation.

---

## Features

- Consistent navigation across all pages
- Proper use of semantic HTML5 elements such as header, nav, main, section, article, and footer
- Images with appropriate alt text
- A table showing the best time to visit selected destinations
- Simple CSS styling for a clean and professional appearance
- Organized folder structure

1. Download or clone the repository.

4. The website will open in your browser.
5. Use the navigation menu to move between pages.
